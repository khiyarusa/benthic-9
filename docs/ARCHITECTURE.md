# معماری BENTHIC-9

## ۱. تصمیم‌های بنیادی

| تصمیم | دلیل |
|---|---|
| Phaser 4.2.1 فقط برای دنیای بازی | رندر، دوربین، اسپرایت و ورودی لمسی؛ منطق بازی در آن نیست |
| React 19 برای رابط مدیریتی | پنل‌های فارسی، RTL و جدول‌های داده در DOM بسیار ساده‌تر از canvas هستند |
| `BenthicSimulationCore` بدون وابستگی به رندر | تست بدون مرورگر، جبرگرایی و امکان اجرای شبیه‌سازی در آینده روی وب‌ورکر |
| Vite 8 | بیلد سریع و پیکربندی ساده با `base: './'` برای Capacitor |
| Capacitor 8.6.0 | بستهٔ اندروید بدون بازنویسی بازی؛ دسترسی به فایل/صدا در آینده |
| Vitest + Playwright | تست دامنه و تست جریان‌های واقعی رابط |

## ۲. لایه‌ها

```
┌────────────────────────────────────────────────────────────┐
│ UI (React)                                                 │
│  App → TitleScreen / GameScreen                            │
│  پنل‌ها: ایستگاه، اتاق، برق، حیات، خدمه، انبار، پژوهش،     │
│          اکتشاف، گزارش/تنظیمات                             │
└───────────────▲───────────────────────────┬────────────────┘
                │ useSyncExternalStore       │ فرمان‌ها (commands)
┌───────────────┴───────────────────────────▼────────────────┐
│ src/state/store.ts  — تک نمونهٔ core + شمارش نسخه           │
└───────────────▲───────────────────────────┬────────────────┘
                │ emit()                    │ tick
┌───────────────┴───────────────────────────▼────────────────┐
│ BenthicSimulationCore (TypeScript خالص)                    │
│  tick: power → life → thermal → hull → crew → research →   │
│        rov → incidents → objectives → failure check        │

                │ read-only state
┌───────────────┴────────────────────────────────────────────┐
│ Phaser StationScene — برش جانبی، آب، خدمه، انتخاب اتاق     │
└────────────────────────────────────────────────────────────┘
```

### جریان داده

- تنها منبع حقیقت `core.state` است. React و Phaser هر دو آن را می‌خوانند و هیچ‌کدام نسخهٔ
  موازی نگه نمی‌دارند.
- React با `useSyncExternalStore` روی شمارندهٔ نسخه مشترک می‌شود؛ هر `emit()` نسخه را یک
  واحد بالا می‌برد و کل درخت را دوباره رندر می‌کند. با گام ۲۵۰ میلی‌ثانیه، هزینهٔ رندر ناچیز
  است.
- Phaser هر ۱۸۰ میلی‌ثانیه یک بازترسیم سبک انجام می‌دهد (آب، ترک، خدمه، انتخاب)؛ هندسهٔ
  ایستگاه یک‌بار کشیده می‌شود.
- انتخاب اتاق از canvas با پل `src/game/bridge.ts` به React می‌رسد و پنل اتاق باز می‌شود.

## ۳. چرا شبیه‌سازی مستقل است

`src/sim/*` هیچ import ای از `react`، `phaser` یا `window` ندارد. تنها استثنا `save.ts` است که
دسترسی به `localStorage` را در `try/catch` انجام می‌دهد. این کار سه چیز می‌دهد:

1. تست دقیق قواعد بازی در Node.
2. جبرگرایی: تمام تصادف‌ها از `Rng` با حالت ذخیره‌شده می‌آیند.
3. امکان تغییر موتور رندر بدون دست‌زدن به قواعد.

## ۴. گام شبیه‌سازی

- هر تیک = ۱ دقیقهٔ بازی. در سرعت ۱× هر ثانیهٔ واقعی یک تیک اجرا می‌شود.
- `advance(realSeconds)` زمان واقعی را جمع می‌کند و حداکثر ۱۲ تیک در هر فراخوانی اجرا می‌کند
  تا پس از بازگشت از پس‌زمینه، پرش انفجاری رخ ندهد.
- با `visibilitychange` بازی به‌طور خودکار متوقف می‌شود؛ هیچ پیشرفت آفلاین وجود ندارد.
- ترتیب سیستم‌ها ثابت است (برق اولین، چون بقیه به توان در دسترس وابسته‌اند).

## ۵. ذخیره‌سازی

- کلید `benthic9.save.v1` در `localStorage`؛ JSON کامل `GameState` با `version`.
- `deserialize` نسخه و فیلدهای کلیدی را اعتبارسنجی می‌کند و دادهٔ خراب را رد می‌کند.
- ذخیرهٔ خودکار هر ۳۰ ثانیه (قابل خاموش‌کردن در تنظیمات) و ذخیرهٔ دستی در پنل گزارش.

## ۶. اندروید

- `capacitor.config.ts`: `appId=ir.citywithoutdawn.benthic9`، `webDir=dist`، طرح `https`.
- `AndroidManifest.xml`: `screenOrientation="sensorLandscape"`، `hardwareAccelerated`، بدون
  دسترسی اینترنت اجباری برای گیم‌پلی.
- `MainActivity`: نگه‌داشتن روشنایی صفحه و حالت تمام‌صفحه با پنهان‌کردن نوارهای سیستم.
- فونت‌ها و همهٔ دارایی‌ها لوکال‌اند؛ بازی کاملاً آفلاین اجرا می‌شود.

## ۷. CI/CD

| گردش‌کار | کار |

## ۸. محدودیت‌های شناخته‌شده

- بیلد Gradle در این ماشین اجرا نشده (JDK 17+ و Android SDK نصب نیست)؛ اعتبارسنجی نهایی
  بیلد اندروید در Actions انجام می‌شود.
- آزمون روی گوشی واقعی انجام نشده است.
- گرافیک به‌صورت رویه‌ای (procedural) در Phaser کشیده می‌شود؛ اطلس پیکسل‌آرت دست‌ساز وجود
  ندارد. ساختار برای جایگزینی با اطلس آماده است.
