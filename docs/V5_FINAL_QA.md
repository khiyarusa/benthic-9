# BENTHIC-9 — V5 QA (dive gameplay)

نسخه: `v0.5.0-alpha.1` · تاریخ: ۱۱ نوامبر ۲۰۲۶

## ۱. چه چیزی واقعاً اضافه شد

**شیرجهٔ دستی ROV** — اولین حلقهٔ گیم‌پلی که فقط «محاسبه» نیست:

- پنج زیستگاه: درهٔ تاریک، میدان چشمه‌های گرمابی، لاشهٔ تحقیقاتی، دشت سنگی، منطقهٔ سیگنال.
- کنترل با لمس: ضربه یا کشیدن انگشت روی آب، ROV به آن نقطه می‌رود.
- چراغ قابل خاموش/روشن (مصرف باتری کم می‌شود، دید کم).
- سونار: پینگ، آشکارسازی موقت نمونه‌ها، هزینهٔ باتری.
- کابل: فراتر از برد، بدنه آسیب می‌بیند و هشدار می‌دهد.
- نمونه‌ها و کشف‌ها با نزدیک‌شدن جمع می‌شوند؛ متن شناور + شمارندهٔ HUD.
- جمع‌بندی: نمونه، داده، آسیب بدنه، مصرف باتری و کشف‌ها مستقیماً در شبیه‌سازی نوشته می‌شوند.

نوشتن نتیجه در وضعیت واقعی: `src/sim/dive.ts` → `resources.samples`, `resources.data`,
`rov.hull`, `rov.batteryPct`, `stats.expeditions`, `flags['codex.*']`, `incidentLog`.

## ۳. آنچه در مرورگر دیده شد (و اصلاح شد)

1. کارت شیرجه با Phaser input کار نمی‌کرد (رویدادها به صحنه نمی‌رسید). حالا کنترل از لایهٔ
   React با رویداد `dive:move` و تبدیل مختصات نرمال‌شده انجام می‌شود.
2. صحنه دو بار start می‌شد و موقعیت ROV ریست می‌شد؛ پارامترها به registry منتقل شدند.
3. با هر tick شبیه‌سازی، overlay با باتری تازه remount می‌شد؛ حالا در لحظهٔ آغاز قفل می‌شود و
   شبیه‌سازی در طول شیرجه متوقف می‌ماند.
4. صحنهٔ قبلی هنگام خروج `cameras` نداشت و هندلرها استثنا می‌دادند؛ همهٔ مسیرها گارد گرفتند.

## ۴. هنوز ناقص (صادقانه)

- خطرهای محیطی (جریان، گرمای چشمه) فقط از طریق کف/دیوار/کابل اثر می‌گذارند، نه مناطق مشخص.
- موجودات فقط تزئینی‌اند و واکنش نشان نمی‌دهند.
- کدکس هنوز UI ندارد؛ کشف‌ها در `flags` ذخیره می‌شوند ولی صفحهٔ مطالعه ساخته نشده.
- کمپین سه‌فصلی، دیالوگ خدمه و مأموریت‌های زنجیره‌ای پیاده نشده.
- موسیقی دارای مجوز و افکت‌های واقعی وجود ندارد.
- تست روی گوشی فیزیکی انجام نشده.
