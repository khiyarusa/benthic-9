# BENTHIC-9 — V2 Art Direction & Design System

نسخهٔ ۰٫۲ — بازطراحی بصری، تجربهٔ افقی و آموزش.

## ۱. هویت

**اقیانوس عمیق صنعتی + سایبرنتیک نظامی + بقا.**

- تیره، آرام، با نورهای نقطه‌ای سرد و هشدارهای کهربایی.
- هیچ سطح تزئینی بدون دادهٔ واقعی وجود ندارد.
- همهٔ متن‌ها فارسی طبیعی، RTL و با ارقام فارسی.

## ۳. تایپوگرافی

- فونت: **Vazirmatn** (لوکال، بدون CDN).
- مقیاس: ۱۰ / ۱۱٫۵ / ۱۲٫۵ / ۱۴ / ۱۷ / ۲۲ / clamp(۴۰–۸۴) برای لوگو.
- اعداد: همیشه فارسی؛ جداکنندهٔ هزارگان `٬` و اعشار `٫`.
- جهت: `dir="rtl"` سراسری؛ اعداد و واحدها با فاصلهٔ مجازی کنترل‌شده.
- برچسب‌های صحنه بر اساس عرض واقعی اتاق مقیاس می‌گیرند (`labelFont = clamp(roomW/15, 10, 19)`).

## ۴. فاصله و شبکه

- واحد پایه: ۴px.
- فاصلهٔ رایج: ۶ / ۸ / ۱۰ / ۱۲ / ۱۶.
- شعاع گوشه: ۳ تا ۶px (بدون گردی زیاد).
- حاشیهٔ ایمن صفحه: `env(safe-area-inset-*)` + حداقل ۶px.
- هدف لمسی: حداقل ۴۴×۴۴ CSS px برای اقدام‌های مهم.

## ۵. چیدمان واکنش‌گرا

صحنه دیگر روی بوم ثابت ۱۹۲۰×۶۴۰ کشیده نمی‌شود.

```
computeLayout(width, height):
  pad    = clamp(min(w,h)·0.022, 6, 18)
  gap    = clamp(min(w,h)·0.016, 5, 14)
  corridorH = clamp(h·0.13, 40, 84)
  roomW = (w − 2·pad − 4·gap)/5      // چهار اتاق + خلیج ROV
  roomH = (h − 2·pad − corridorH − 2·gap)/2
```

- دو ردیف اتاق، راهروی مرکزی بین آن‌ها، خلیج ROV در ستون پنجم با ارتفاع کامل.
- دوربین روی `zoom = 1` و مختصات برابر پیکسل CSS است؛ هیچ مقیاس‌کشی تصویر وجود ندارد.
- با `ResizeObserver` و رویداد resize، چیدمان با تأخیر ۱۸۰ms بازسازی می‌شود.
- در ارتفاع کم (≤ ۴۲۰px) نوارها فشرده می‌شوند اما برچسب‌ها حذف نمی‌شوند.

## ۶. لایه‌های صحنه

1. گرادیان عمق (۲۲ باند).
2. صخره‌های دور و برج رهاشده.
3. پرتوهای نور افزودنی.
4. برف دریایی (ذرات).
5. سیلوئت ماهی‌ها (حرکت آرام).
6. بدنه و اتاق‌ها (فریم، پنل، پرچ، لامپ، دریچه، گیج، لوله).
7. لایهٔ دینامیک: آب، ترک، جرقه، انتخاب، فوکوس آموزش.
8. خدمه (اسپرایت پیکسلی + برچسب نام).

## ۸. آموزش

- کارت گفت‌وگو با پرترهٔ پیکسلی «آرمان کیانی».
- اسپات‌لایت واقعی روی عنصر هدف (`box-shadow` با گسترش ۹۹۹۹px).
- تمرکز دوربین روی اتاق مرتبط با هر گام.
- ۱۲ گام با شرط واقعی (رویداد UI یا وضعیت شبیه‌سازی).
- ذخیرهٔ پیشرفت در `benthic9.tutorial.v2`؛ توقف/ادامه/شروع دوباره از «راهنمای فرمانده».
